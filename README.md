# Milli Time Tracker

[![Latest Release](https://img.shields.io/github/v/release/dartDgtl/MilliTimeTracker-Releases?label=latest)](https://github.com/dartDgtl/MilliTimeTracker-Releases/releases/latest)
[![Platform](https://img.shields.io/badge/platform-Windows-blue)](https://github.com/dartDgtl/MilliTimeTracker-Releases/releases/latest)

Лёгкий трекер времени для Windows. Работает в фоне, автоматически фиксирует активные окна и показывает, на что уходит рабочее время.

**Бесплатно. Локально. Без аккаунтов и телеметрии.**

## Что делает

- Работает в фоне (трей), без отдельного окна поверх других программ.
- Определяет активное окно раз в секунду и записывает время в локальную БД.
- Ставит отсчёт на паузу, если пользователь отошёл от компьютера (порог простоя настраивается).
- Показывает детальную статистику по программам и вкладкам за любой день или период.
- Позволяет исключать ненужные программы из трекинга и очищать историю.
- Все данные хранятся локально на компьютере пользователя и никуда не отправляются.

## Установка

1. Скачайте последний установщик со [страницы Releases](https://github.com/dartDgtl/MilliTimeTracker-Releases/releases/latest) — файл `MilliTimeTrackerSetup-*.exe`.
2. Запустите установщик и следуйте шагам мастера.
3. После установки приложение запустится автоматически, появится иконка в системном трее.
4. По желанию включите «Запускать при входе в систему» в разделе «Настройки» → «Общие».

## Системные требования

- ОС: Windows 10 или Windows 11 (x64).
- Свободное место: ~150 МБ.
- Зависимости: не требуются. Все необходимые библиотеки .NET и графические компоненты включены в установщик.

## Первый запуск

При первом запуске Milli Time Tracker открывается окно на странице «Детализация». Дальше приложение работает в фоне — окно можно закрыть (иконка в трее останется). Вернуться — клик по иконке в трее.

## Где хранятся данные

Всё локально, в `%APPDATA%\MilliTimeTracker\`:

- `data.db` — история трекинга (SQLite).
- `settings.json` — настройки приложения.

Никакие данные не отправляются на серверы, телеметрия отсутствует.

## Удаление

1. Откройте «Параметры → Приложения → Установленные приложения».
2. Найдите MilliTimeTracker и нажмите «Удалить».

История трекинга в `%APPDATA%\MilliTimeTracker\` **не удаляется автоматически** — если нужно, удалите папку вручную.

## Технологии

- Avalonia UI — кроссплатформенный XAML-фреймворк для интерфейса.
- .NET 10 — рантайм.
- SQLite — локальное хранилище.
- SkiaSharp / Svg.Controls.Skia.Avalonia — графика и SVG-иконки.
